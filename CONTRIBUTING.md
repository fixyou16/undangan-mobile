# Contributing Guide

Terima kasih sudah ingin berkontribusi.

## Langkah kontribusi
1. Fork repository
2. Buat branch baru
3. Lakukan perubahan
4. Jalankan build lokal
5. Buat pull request

## Style
- Gunakan Kotlin style yang rapi
- Sederhanakan UI agar mudah demo
- Hindari hardcode text terlalu banyak, gunakan resource string

## Build check
```bash
./gradlew assembleDebug
```
